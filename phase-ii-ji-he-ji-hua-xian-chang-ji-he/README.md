# Phase II 稽核計畫/現場稽核



## 系統需求描述



#### 稽核類型

制定月計畫時需要選擇稽核類型

例行稽核：(事先計劃)

無預警稽核：(事先計劃) 有“部分”廠區供應商每三個月例行稽核有一次會無預警

專案稽核：(執行期間無預期發生) 如果中間有異常事件時的加開場次

新供應商評估：(執行期間無預期發生) 新的長期供應商評估時需要先有現場稽核



#### 基礎資料關聯

-廠區關聯供應商

-廠區、供應商關聯作業區

-作業區關聯頻率(作業頻率每年可能變更)
